# Audit Dokumen Prinsip Mengenali Pengguna Jasa

Dokumen lampiran yang diaudit adalah `KSPPrinsipMengenaliPenggunaJasa.docx` dan `USPPrinsipMengenaliPenggunaJasa.docx` dari unggahan pengguna. Keduanya merupakan dokumen peraturan/template PMPJ dengan lampiran profil anggota, profil koperasi lain, checklist pemenuhan PMPJ, serta catatan revisi dokumen.

Kartu template aktif yang akan diperbarui:

- KSP: `ksp-kmp`, judul saat ini `Peraturan tentang Prinsip Mengenali Pengguna Jasa KSP`, metadata `Persyaratan KSP 09`.
- USP: `usp-kmp`, judul saat ini `Peraturan tentang Prinsip Mengenali Pengguna Jasa USP`, metadata `Persyaratan USP 10`.

Pemetaan daftar Unduh Semua tetap menggunakan kedua ID tersebut. Integrasi harus mempertahankan tab KSP/USP, preview PDF, tombol Word, tombol PDF, pencarian, dan Unduh Semua.
